# BRIDGE

BRIDGE is an interactive app for multi-omics data exploration, analysis, and integration. It is designed to let users work through a full workflow in a GUI, from loading curated datasets to generating plots and integrated views across omics layers.

Supported data types:

- Proteomics
- Phosphoproteomics
- RNA-seq

What this guide covers:

- Getting to a first successful plot
- Installing and running BRIDGE
- Creating and validating the SQLite database
- Loading datasets correctly
- Using each analysis module
- Running raw and processed integration
