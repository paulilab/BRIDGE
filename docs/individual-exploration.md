# Individual Exploration

Each loaded table gets its own analysis workspace in BRIDGE.

Inside each workspace you can:

- view the table with filtering/export options
- run visualization modules independently
- adjust thresholds and parameters per module

Module pages:

- [Raw Heatmap](raw-heatmap.md)
- [DE Heatmap](de-heatmap.md)
- [Volcano Plot](volcano-plot.md)
- [Gene Expression](gene-expression.md)
- [Enrichment Analysis](enrichment-analysis.md)
- [PCA](pca.md)

Recommended usage order:

1. Raw Heatmap or PCA for global view.
2. DE Heatmap and Volcano for differential signals.
3. Gene Expression for candidate-level inspection.
4. Enrichment for biological interpretation.
